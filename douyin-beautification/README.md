# 抖音直播美化 - 纯净沉浸版

> 一个让抖音网页版直播间回归「只看内容」的 Tampermonkey 用户脚本。

抖音网页版直播间默认会同时展示顶部主播信息、右侧聊天、底部礼物栏、全屏弹幕和各类活动提示。这个脚本用一套轻量的 `document-start` 样式净化 + 原生控制条增强，把画面留给直播本身，并且**默认静音**，打开直播间不会突然外放。

---

## 功能一览

### 界面净化

| 功能 | 默认 | 说明 |
|---|:---:|---|
| 精简顶部信息栏 | ✅ | 隐藏主播信息、榜单、关注和退出按钮，仅保留自定义悬浮顶栏 |
| 隐藏右侧聊天区 | ✅ | 隐藏 320px 聊天/观众列表，直播画面自动扩展至全窗口 |
| 隐藏礼物栏 | ✅ | 移除底部礼物入口与礼物横幅 |
| 隐藏礼物特效 | ✅ | 不再弹出全屏礼物动画 |
| 隐藏弹幕 | ✅ | 调用抖音原生弹幕开关（`B`）停止弹幕渲染，按 `D` 可随时开关 |
| 隐藏活动与提示 | ✅ | 屏蔽红包、活动浮层、试看提示等服务提示 |
| 隐藏点赞与特效 | ✅ | 关闭飘心、点赞动画 |
| 隐藏水印与广告 | ✅ | 隐藏播放器水印与广告标识 |

### 播放体验

| 功能 | 默认 | 说明 |
|---|:---:|---|
| 默认静音 | ✅ | 进入直播间自动将视频音量归零，告别突发外放 |
| 自动最高画质 | ✅ | 优先切换当前可用的最高画质，已是最佳档位时不会重复操作 |
| 显示悬浮顶栏 | ✅ | 左上角保留主播名、返回和设置入口 |
| 氛围光效 | ✅ | 在竖屏直播左右黑边渲染柔和的渐变背景，避免大面积死黑 |
| 弹幕开关快捷键 | `D` | 调用抖音原生弹幕开关，显示或隐藏画面弹幕，可在「播放体验」中点击后重新录制 |
| 播放/暂停快捷键 | `Space` | 一键暂停或继续直播画面，可在「播放体验」中点击后重新录制 |
| 全屏快捷键 | `F` | 一键切换直播原生全屏，可在「播放体验」中点击后重新录制 |

### 交互

- 点击左上角**齿轮**打开设置面板；
- 设置**即时生效**并自动保存；
- 快捷键：`Space` 暂停/继续直播（可自定义），`D` 显示/隐藏弹幕（可自定义，实际调用抖音原生弹幕开关），`F` 切换直播全屏（可自定义），`Alt + D` 呼出/收起设置面板，`Alt + M` 切换静音；
- 抖音原生的 `D`（旋转画面）、`H`（原生全屏）与 `B`（弹幕开关）已被屏蔽，按下不再触发页面行为；脚本自己需要切换弹幕时会放过一个合成的 `B` 事件给抖音的原生开关；
- Tampermonkey 菜单也提供「打开设置 / 切换静音 / 弹幕开关 / 播放暂停 / 切换全屏 / 恢复默认」六个入口；
- 面板使用 Shadow DOM 隔离，不会被抖音页面样式污染。

## 安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://scriptcat.org/)；
2. 点击 **[⚡ 一键安装《抖音直播美化》](https://github.com/e69d8e/tampermonkey-scripts/raw/main/douyin-beautification/douyin-beautification.user.js)**；
3. 在脚本管理器弹出的安装页点击「安装」；
4. 打开任意抖音网页版直播间，例如 `https://live.douyin.com/148108118778`。

> 脚本仅匹配 `live.douyin.com` 直播间路径与 `www.douyin.com` 的直播路径，不会影响抖音首页、短视频、私信等页面。

## 使用说明

### 第一次打开

脚本会自动应用默认净化配置：

- 视频自动静音；
- 聊天区、礼物栏、弹幕、活动提示被隐藏；
- 播放器自动铺满浏览器窗口；
- 左上角出现「抖音直播 / 主播名 / 齿轮」悬浮顶栏。

### 设置面板

点击齿轮后可以看到两个分组：

- **界面净化**：8 个隐藏类开关；
- **播放体验**：静音、自动画质、悬浮顶栏、氛围光效、弹幕开关快捷键、播放/暂停快捷键、全屏快捷键。

每次修改都会立即写入 Tampermonkey 的本地存储，不需要刷新页面。点击「恢复默认」可以把全部选项恢复成上表的默认值。

### 快捷键

| 快捷键 | 功能 |
|---|---|
| `Space` | 暂停 / 继续直播画面（可在「播放体验」中自定义） |
| `D` | 显示 / 隐藏画面弹幕（调用原生弹幕开关，可在「播放体验」中自定义） |
| `F` | 切换直播原生全屏（可在「播放体验」中自定义） |
| `Alt + D` | 打开 / 关闭设置面板 |
| `Alt + M` | 切换直播静音 |
| `Esc` | 关闭设置面板 |

自定义方式：打开「播放体验」→ 点击「弹幕开关快捷键」「播放/暂停快捷键」或「全屏快捷键」→ 按下新的按键；按 `Esc` 取消录制。三个快捷键不能重复，与抖音原生快捷键（`Y` / `U`）及 `Alt + D` / `Alt + M` / `Esc` / `Tab` 冲突的组合也会被拒绝。抖音原生的 `D`（旋转）、`H`（全屏）与 `B`（弹幕开关）已被脚本接管，不再触发页面行为，因此可以安全地把 `D` / `H` / `B` 录制为新快捷键。脚本切换弹幕时会向页面派发一个带内部放行标记的合成 `B`，由抖音自己的弹幕开关处理，因此即使把 `B` 录制为其它快捷键也不会互相干扰。焦点在聊天输入框时不会触发快捷键。

## 配置项

配置保存在 `GM_setValue('douyinBeautifyConfig')`，未安装用户脚本时会降级为 `localStorage`。完整配置模型：

```typescript
interface DouyinBeautifyConfig {
    hideHeader: boolean;         // 精简顶部信息栏
    hideChat: boolean;           // 隐藏右侧聊天区
    hideGiftBar: boolean;        // 隐藏底部礼物栏
    hideGiftEffects: boolean;    // 隐藏礼物特效
    hideDanmaku: boolean;        // 调用原生弹幕开关，停止弹幕渲染
    hideActivity: boolean;       // 隐藏活动、提示与悬浮挂件
    hideLikeEffects: boolean;    // 隐藏点赞动效
    hideWatermark: boolean;      // 隐藏水印与广告
    muteLive: boolean;           // 默认静音
    autoHighestQuality: boolean; // 自动选择可用最高画质
    showTopbar: boolean;         // 显示自定义悬浮顶栏
    ambientGlow: boolean;        // 竖屏黑边氛围光效
    danmakuShortcut: string;     // 显示/隐藏弹幕快捷键，默认 'd'
    playPauseShortcut: string;   // 暂停/继续直播快捷键，默认 'space'
    fullscreenShortcut: string;  // 直播原生全屏快捷键，默认 'f'
}
```

## 常见问题

**Q：安装后没有生效？**

1. 确认地址是 `https://live.douyin.com/房间号`，而不是抖音首页或短视频页；
2. 确认 Tampermonkey 已启用该脚本；
3. 刷新直播间页面。脚本使用 `document-start` 注入样式，刷新后会在首屏渲染前完成净化。

**Q：为什么还有黑边？**

竖屏直播的视频比例是 9:16，在 16:9 的浏览器窗口中按 `object-fit: contain` 完整显示时必然会有左右留白。脚本不会裁切画面，而是把黑边替换成柔和的深色渐变氛围光；如果喜欢纯黑，可以在「播放体验」中关闭「氛围光效」。

**Q：自动最高画质没有切换？**

脚本会读取画质菜单中的所有档位，跳过未登录时带「登录即享」标识的选项。登录后优先切换「原画 / 蓝光 / 超清」，未登录时最高为「高清」；不会主动点击需要登录的档位，也不会触发登录弹窗。

**Q：静音后还能恢复声音吗？**

可以。打开设置面板关闭「默认静音」，或按 `Alt + M`。也可直接使用播放器原生音量按钮。

**Q：会不会修改视频内容？**

不会。脚本只通过 CSS 隐藏页面元素、调整播放器布局、设置 `video.muted`，并调用抖音自带的弹幕开关停止弹幕渲染，不下载、不录制、不修改直播流，也不会绕过登录或付费限制。

## 技术说明

- **零闪烁净化**：脚本在 `document-start` 注入全局 CSS，先隐藏冗余元素，避免页面渲染完成后再闪烁。
- **不删除 React 节点**：抖音直播间由 React/Webcast 渲染，脚本只使用 `display: none !important`，不调用 `.remove()`，避免 React 更新时崩溃。
- **稳定 ID 优先**：隐藏规则优先使用 `#RightBackgroundLayout`、`#GiftEffectLayout` 等相对稳定的节点 ID，并用类名选择器兜底。
- **原生弹幕开关**：弹幕层不再用 CSS 隐藏，关闭弹幕时直接在 `document.body` 上派发一个合成 `keydown`（`B`，带内部放行标记），交给抖音自己的快捷键逻辑移除弹幕 `<canvas>`，让弹幕渲染真正停止；脚本启动时先对齐一次，播放器容器里出现新的弹幕 `<canvas>`（切画质、页面重新开启弹幕等）时在绘制前立刻再次关闭，所以去掉 CSS 兜底也不会闪；状态按 `<canvas>` 是否存在判断，与配置不一致时在 600ms 后复查并最多重试 3 次，3 秒兜底巡检也会校正。
- **Shadow DOM 设置面板**：自定义 UI 挂在独立的 Shadow Root 中，不受抖音全局样式影响，也不会污染页面 CSS。
- **MutationObserver 守护**：只监听 `html` / `body` 的直接子节点与播放器容器内部的视频、弹幕 canvas 变化，聊天区、礼物动画等高频 DOM 更新不进入回调；另有 3 秒兜底巡检负责重新挂载、刷新主播名与恢复静音。
- **渲染节流**：设置面板内容未变化时跳过 Shadow DOM 重建，提示条改为局部更新，快捷键反馈不再整面板重绘。

## 更新记录

### v0.0.5 (2026-11-18)

- 删除旧「纯 CSS 隐藏弹幕」方案的残留：`#DanmakuLayout` / `.CanvasDanmakuPlugin` 不再进 `display: none` 规则，弹幕完全由抖音原生开关控制；
- 播放器容器里出现新的弹幕 `<canvas>` 时立即再次关闭（在浏览器绘制前完成），脚本启动时也会先对齐一次，因此去掉 CSS 兜底不会闪出弹幕；
- 弹幕开关切换时不再重建全局样式，少一次样式重算。

### v0.1.5 (2026-11-18)

- 弹幕开关改为调用抖音原生弹幕开关（`B`）：隐藏弹幕时移除弹幕 `<canvas>`，真正停止弹幕渲染，而不是只做 CSS 隐藏；
- 新增原生状态同步与复查机制：按 `<canvas>` 是否存在判断状态，必要时重试，兜底巡检也会校正，避免脚本开关与原生状态不一致；
- 重新开启弹幕时先移除 CSS 隐藏并补发原生开关，避免状态翻反或连续闪动。

- 性能优化：MutationObserver 不再监听聊天区等高频子树，设置面板增加渲染缓存，提示条改为局部更新，并新增 3 秒兜底巡检；
