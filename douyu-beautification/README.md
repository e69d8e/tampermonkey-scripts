# 斗鱼直播美化 — 极简纯净版 — 使用教程

> 本教程面向零基础用户，每一步都有详细说明，跟着做就行。

## 这个东西是什么？

这是一个**浏览器插件的辅助脚本**。安装后，打开斗鱼直播间，它会自动帮你：

- 移除所有广告、礼物栏、活动弹窗、侧边推荐等冗余元素
- 播放器自动扩展为全屏宽度
- 自动选择最高画质

最终效果：直播间只剩视频播放器，干净纯粹。

---

## 安装前的准备

你只需要准备一样东西：

| 序号 | 准备什么 | 在哪里弄 |
|:---:|---|---|
| 1 | **Tampermonkey 浏览器插件** | 浏览器扩展商店（下面会教） |

> **什么是 Tampermonkey？** 俗称"油猴"，是一个浏览器插件，用来运行各种辅助脚本。

---

## 第一步：安装 Tampermonkey 插件

### 用什么浏览器？

推荐使用以下任一浏览器（电脑端）：

- **Edge**（Windows 自带，推荐）
- **Chrome**（谷歌浏览器）
- **Firefox**（火狐浏览器）

### 安装步骤

1. 点击下面对应你浏览器的链接，进入插件安装页面：

   - [Edge 浏览器安装 Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
   - [Chrome 浏览器安装 Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - [Firefox 浏览器安装 Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/)

2. 在打开的页面中，点击 **"获取"** 或 **"添加到浏览器"** 按钮

3. 浏览器会弹出提示问你是否允许，点击 **"添加扩展"** 或 **"确认"**

4. 安装完成后，浏览器右上角工具栏会出现 Tampermonkey 的图标（一个黑色圆脸上带两个角）

> **找不到图标？** 点击浏览器右上角的拼图图标 🧩（扩展管理），在列表里找到 Tampermonkey，点击旁边的图钉 📌 把它固定到工具栏。

---

## 第二步：安装美化脚本

### 方式一：一键直接安装（最推荐 ⚡）

1. 确保你已经完成了【第一步】，且浏览器中的 Tampermonkey 插件已处于启用状态。
2. 点击下方官方源链接：
   👉 [一键安装/更新《斗鱼直播美化》脚本](https://github.com/e69d8e/tampermonkey-scripts/raw/main/douyu-beautification/douyu-beautification.user.js)
3. Tampermonkey 会自动识别并弹出安装确认页面，点击 **"安装"**（或“更新”）按钮即可。
4. 安装完成后，该页面会自动关闭，脚本即生效。

---

### 方式二：手动导入安装

如果因为网络环境无法直接一键安装，你可以手动下载文件导入：

1. **下载脚本文件**：
   * 在本仓库项目中找到 **[`douyu-beautification.user.js`](./douyu-beautification.user.js)** 文件并下载到本地。
   * 确保文件后缀名为 `.user.js`。
2. 点击浏览器右上角的 **Tampermonkey 图标**。
3. 在弹出的菜单中，点击 **"管理面板"**。
4. 在新页面顶部，点击最右边的 **"实用工具"** 标签页。
5. 找到 **"从文件导入"** 这一栏，将下载好的文件直接拖进虚线框中。
6. 页面会弹出确认信息，点击 **"导入"** 或 **"安装"** 即可。

## 第三步：开始使用与交互说明

1. 打开任意一个斗鱼直播间（网址是 `www.douyu.com`）。
2. 脚本会在 `document-start` 阶段自动执行，首屏注入净化样式，无视觉闪烁（Zero FOUC）。
3. 页面加载完成后，顶部导航栏右侧会自动挂载一个原生的 **⚡「美化设置」** 按钮。
4. 点击该按钮即可展开设置浮层；也可以在浏览器右上角 Tampermonkey 扩展菜单中选择 **“⚡ 斗鱼美化 - 打开设置”**。

---

## 设置面板与功能清单

设置面板支持 **即时热生效 (Live Reactive CSS)**：开关点击后立即通过动态样式引擎刷新 DOM，并伴有轻量 Toast 提示，大部分项无需手动刷新网页。

### 1. 界面元素清理 (10 项)

| 设置项 | 默认状态 | 作用与清理目标 |
|---|:---:|---|
| 精简顶部导航 | ✅ | 仅保留搜索、关注、消息、头像等高频项，移除冗余推广图标 |
| 移除右侧边栏 | ✅ | 隐藏右侧聊天区与弹幕滚动列表，彻底释放横向空间 |
| 移除礼物栏 | ✅ | 隐藏播放器下方的礼物赠送横条、打赏特效及贵族入场通道 |
| 移除页脚 | ✅ | 隐藏网站最底部的版权、合作伙伴与链接页脚 |
| 移除广告 | ✅ | 屏蔽直播间内嵌的各类横幅商业推广与联盟广告 |
| 移除水印 | ✅ | 隐藏视频画面右上角斗鱼平台水印 |
| 移除活动与皮肤 | ✅ | 屏蔽全站任务、抽奖弹窗以及主播置顶的活动背景皮肤 |
| 移除侧边工具条 | ✅ | 隐藏悬浮在页面右侧/底部的活动任务小挂件 |
| 精简下方与遮挡 | ✅ | 移除播放器下方的任务大厅、游戏租号、互动横条及评论区 |
| 精简信息栏 | ✅ | 移除主播头顶的粉丝勋章、贵族头衔、主播等级等花哨装饰 |

### 2. 播放体验增强 (4 项)

| 设置项 | 默认状态 | 作用与机制 |
|---|:---:|---|
| 播放器扩展大窗 | ✅ | 普通模式下保持 16:9 居中自适应视野；全屏下 100% 满屏无下边距黑边 |
| 自动最高画质 | ✅ | 异步轮询视频控制条，首选蓝光/原画最高可用码率 |
| 自动网页全屏 | ❌ | 进入直播间后自动模拟点击切换网页全屏 |
| 保留聊天面板 | ❌ | 特别保留右侧弹幕聊天区（开启后将覆盖「移除右侧边栏」选项） |

> **配置热持久化**：所有选项在切换瞬间自动通过 `GM_setValue` 写入本地存储。如需全量重载页面，可点击面板底部的 **“保存并刷新”**。

## 关于快捷键的设计说明

在早期版本中曾提供过单按键快捷键。为彻底避免与斗鱼原生播放器内置快捷键、全屏切换手势以及输入法打字产生任何按键冲突，**v0.0.1 起已全面移除单按键监听**。

所有的设置呼出统一收归至顶部导航栏按钮及 Tampermonkey 原生扩展菜单，保证极速且无干扰的观看体验。

## 常见问题

### 脚本没有生效
- 确认你访问的是斗鱼网页（网址匹配 `douyu.com`）。
- 点击浏览器右上角 Tampermonkey 图标，确认 **"斗鱼直播美化 - 极简纯净版"** 处于勾选启用状态。
- 如果刚安装，建议强制刷新页面（`Ctrl + F5` 或 `Cmd + Shift + R`）。

### 顶部导航栏没有出现「美化设置」按钮
- 斗鱼在不同直播间（如赛事直播间、特殊活动间）使用了不同的头部导航 DOM 结构。脚本已内置了多组选择器自动重试挂载。如果偶发未挂载，可直接点击浏览器右上角油猴图标，选择菜单命令中的 **“⚡ 斗鱼美化 - 打开设置”** 唤起面板。

### 某个广告或活动横条未被完全拦截
- 斗鱼页面结构会不定期进行动态更新或混淆。可以在设置面板中尝试点击 **“恢复默认”**，或者点击 **“保存并刷新”** 重新触发完整的 DOM 暴力清理逻辑。
