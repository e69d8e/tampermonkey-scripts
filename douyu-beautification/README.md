# 斗鱼直播美化 — 极简纯净版 — 使用教程

> 本教程面向零基础用户，每一步都有详细说明，跟着做就行。

## 这个东西是什么？

这是一个**浏览器插件的辅助脚本**。安装后，打开斗鱼直播间，它会自动帮你：

- 移除所有广告、礼物栏、活动弹窗、侧边推荐等冗余元素
- 播放器自动扩展为全屏宽度
- 自动选择最高画质
- 空格沿用斗鱼原生暂停/继续，另支持自定义 `F` 全屏、`H` 网页全屏、`D` 弹幕开关

最终效果：直播间只剩视频播放器，干净纯粹。

## 第三步：开始使用与交互说明

1. 打开任意一个斗鱼直播间（网址是 `www.douyu.com`）。
2. 脚本会在 `document-start` 阶段自动执行，首屏注入净化样式，无视觉闪烁（Zero FOUC）。

### 3. 自定义快捷键

播放体验标签页底部提供**三个**快捷键设置（全屏、网页全屏、弹幕开关），点击后按下新按键即可修改，按 `Esc` 取消。播放/暂停不在面板中设置——`Space` 沿用斗鱼页面自带的能力，脚本只在页面处理不到位时被动兜底。

| 功能 | 默认按键 | 说明 |
|---|:---:|---|
| 全屏 | `F` | 切换播放器原生全屏（隐藏浏览器地址栏） |
| 网页全屏 | `H` | 切换斗鱼网页全屏（页面内铺满，保留浏览器界面） |
| 弹幕开关 | `D` | 显示或隐藏画面弹幕 |

- 快捷键在文本输入框、文本域、下拉框、可编辑区域内不会触发，聊天打字不受影响；设置面板内开关聚焦时仍可使用（会拦截按键对控件的默认激活，不会误触开关）。
- 与其他快捷键重复时会提示冲突，且不接受 `Esc`/`Tab`/`Enter` 等系统保留键。
- 页面自身热键会重复派发合成按键事件，脚本只响应真实用户输入，避免一次按键触发两遍。

> **配置热持久化**：所有选项在切换瞬间自动通过 `GM_setValue` 写入本地存储。如需全量重载页面，可点击面板底部的 **“保存并刷新”**。

## 关于快捷键的设计说明

v0.0.6 起，`Space` **完全交回斗鱼原生播放/暂停**：脚本不拦截、不模拟点击，面板里也不再提供播放/暂停快捷键（不可改键）。脚本只在按键后 450ms 检查一次——页面完全没响应、或暂停后又被播放器自动拉起时，才补一次暂停并保持 6 秒；页面正常暂停时不重复操作。这样不会因为不同直播间的播放器实现不同而把空格「吃掉」。只有全屏（默认 `F`）、网页全屏（默认 `H`）和弹幕开关（默认 `D`）由脚本接管：监听挂在 `window` 捕获阶段，只在按键命中已配置的快捷键时拦截页面默认行为，其余按键完全放行；文本输入场景（输入框、文本域、下拉框、可编辑区域）不会触发，因此不影响聊天打字。

所有快捷键都可以在面板中重新录制；如果担心误触，录制一个不常用的按键即可。面板和油猴菜单里的「播放 / 暂停直播」命令仍会调用脚本自己的播放控制逻辑。

## 常见问题

### 脚本没有生效
- 确认你访问的是斗鱼网页（网址匹配 `douyu.com`）。
- 点击浏览器右上角 Tampermonkey 图标，确认 **"斗鱼直播美化 - 极简纯净版"** 处于勾选启用状态。
- 如果刚安装，建议强制刷新页面（`Ctrl + F5` 或 `Cmd + Shift + R`）。

### 顶部导航栏没有出现「美化设置」按钮
- 斗鱼在不同直播间（如赛事直播间、特殊活动间）使用了不同的头部导航 DOM 结构。脚本已内置了多组选择器自动重试挂载。如果偶发未挂载，可直接点击浏览器右上角油猴图标，选择菜单命令中的 **“⚡ 斗鱼美化 - 打开设置”** 唤起面板。

### 某个广告或活动横条未被完全拦截
- 斗鱼页面结构会不定期进行动态更新或混淆。可以在设置面板中尝试点击 **“恢复默认”**，或者点击 **“保存并刷新”** 重新触发完整的 DOM 暴力清理逻辑。

### 右侧聊天/弹幕列表不见了？
- 脚本默认开启「隐藏聊天面板」，会把整块聊天列表一起隐藏。到 **播放体验 → 隐藏聊天面板** 关闭即可恢复。
- 画面上的滚动弹幕由 **隐藏画面弹幕** 控制，两者互不影响，快捷键 `D` 只切换画面弹幕。

### 按空格没有暂停？
- 请确认脚本已更新到 v0.0.6 并刷新直播间；已打开的旧页面不会自动加载新脚本。
- v0.0.6 起 `Space` **完全交给斗鱼页面自己的播放/暂停逻辑**，脚本不拦截、不模拟点击，也没有「播放/暂停快捷键」设置项；脚本只在 450ms 后检查一次，页面没响应或暂停后又被自动拉起时补一次暂停。若空格无效，请先关闭脚本对比：若关闭后同样无效，就是斗鱼页面/浏览器的问题，与脚本无关。
- 若焦点在聊天输入框内，空格会正常输入文字而不会暂停，点击视频画面或页面空白处后再试。
- 若焦点在页面内嵌的 iframe 中，顶层页面收不到按键；点击视频画面恢复焦点即可。

- `D` 隐藏画面弹幕时同时覆盖 `[class*="danmuItem"]` 单个弹幕节点，避免容器外挂节点漏网。
- 将「移除右侧边栏」与「保留聊天面板」两个反向开关合并为播放体验中的「隐藏聊天面板」（默认开启），旧配置会自动换算，不再出现两个开关互相打架的情况。
