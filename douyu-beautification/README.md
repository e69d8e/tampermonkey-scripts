# 斗鱼直播美化 — 极简纯净版 — 使用教程

> 本教程面向零基础用户，每一步都有详细说明，跟着做就行。

## 这个东西是什么？

这是一个**浏览器插件的辅助脚本**。安装后，打开斗鱼直播间，它会自动帮你：

- 移除所有广告、礼物栏、活动弹窗、侧边推荐等冗余元素
- 播放器自动扩展为全屏宽度
- 自动选择最高画质

最终效果：直播间只剩视频播放器，干净纯粹。

---

## 安装前的准备

你只需要准备一样东西：

| 序号 | 准备什么 | 在哪里弄 |
|:---:|---|---|
| 1 | **Tampermonkey 浏览器插件** | 浏览器扩展商店（下面会教） |

> **什么是 Tampermonkey？** 俗称"油猴"，是一个浏览器插件，用来运行各种辅助脚本。

---

## 第一步：安装 Tampermonkey 插件

### 用什么浏览器？

推荐使用以下任一浏览器（电脑端）：

- **Edge**（Windows 自带，推荐）
- **Chrome**（谷歌浏览器）
- **Firefox**（火狐浏览器）

### 安装步骤

1. 点击下面对应你浏览器的链接，进入插件安装页面：

   - [Edge 浏览器安装 Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
   - [Chrome 浏览器安装 Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - [Firefox 浏览器安装 Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/)

2. 在打开的页面中，点击 **"获取"** 或 **"添加到浏览器"** 按钮

3. 浏览器会弹出提示问你是否允许，点击 **"添加扩展"** 或 **"确认"**

4. 安装完成后，浏览器右上角工具栏会出现 Tampermonkey 的图标（一个黑色圆脸上带两个角）

> **找不到图标？** 点击浏览器右上角的拼图图标 🧩（扩展管理），在列表里找到 Tampermonkey，点击旁边的图钉 📌 把它固定到工具栏。

---

## 第二步：安装美化脚本

### 方式一：直接安装（最推荐 ⚡）

1. 确保你已经完成了【第一步】，且浏览器中的 Tampermonkey 插件已处于启用状态。
2. 点击下方链接：
   👉 [`douyu-beautification.user.js`](./douyu-beautification.user.js)
3. Tampermonkey 会自动识别并弹出安装确认页面，点击 **"安装"** 按钮即可。
4. 安装完成后，该页面会自动关闭，脚本即生效。

---

### 方式二：手动导入安装

如果直接安装失败，你可以手动下载文件导入：

1. **下载脚本文件**：
   * 在本仓库主页找到 **`douyu-beautification.user.js`** 文件并下载到电脑上。
   * 确保文件后缀名为 `.user.js`。
2. 点击浏览器右上角的 **Tampermonkey 图标**（那个黑色小脸）。
3. 在弹出的菜单中，点击 **"管理面板"**。
4. 在新页面顶部，点击最右边的 **"实用工具"** 标签页。
5. 找到 **"从文件导入"** 这一栏，将下载好的文件直接拖进虚线框中。
6. 页面会弹出确认信息，点击 **"导入"** 或 **"安装"** 即可。

> **备用方式：** 如果拖拽导入失败，可以在管理面板中点击顶部的 **"+"** 号，打开代码编辑器。用记事本打开下载好的 `.user.js` 文件，复制全部代码粘贴进去，按 `Ctrl + S` 保存。

---

## 第三步：开始使用

1. 打开任意一个斗鱼直播间（网址是 `www.douyu.com`）
2. 脚本会自动生效 — 页面加载后，多余的元素已经被移除
3. 播放器会自动扩展为全屏宽度，并选择最高画质

> **页面右下角**会出现一个齿轮按钮，点击可打开设置面板。

---

## 设置面板

按 `Alt + S` 或点击页面右下角齿轮按钮打开设置面板。

### 元素清理

| 设置项 | 默认 | 说明 |
|---|:---:|---|
| 精简顶部导航 | ✅ | 仅保留搜索、关注、消息、头像 |
| 移除右侧边栏 | ✅ | 隐藏弹幕/聊天区域 |
| 移除礼物栏 | ✅ | 隐藏礼物赠送区域 |
| 移除页脚 | ✅ | 隐藏底部页脚信息 |
| 移除广告 | ✅ | 屏蔽所有广告元素 |
| 移除水印 | ✅ | 隐藏播放器水印 |
| 移除活动弹窗 | ✅ | 屏蔽任务/活动/抽奖弹窗 |
| 移除侧边横幅 | ✅ | 隐藏浮动按钮和侧边栏 |
| 精简视频下方 | ✅ | 移除工具栏、推荐、评论等 |
| 精简信息栏 | ✅ | 移除粉丝勋章、贵族图标等 |

### 功能增强

| 设置项 | 默认 | 说明 |
|---|:---:|---|
| 播放器全宽 | ✅ | 播放器扩展为全屏宽度 |
| 自动最高画质 | ✅ | 自动选择最高可用画质 |
| 自动网页全屏 | ❌ | 进入直播间自动网页全屏 |
| 保留聊天面板 | ❌ | 保留右侧弹幕聊天区 |

> 设置只需要配置一次，以后打开会自动记住。修改后点击 **"应用并刷新"** 按钮生效。

## 常见问题

### 脚本没有生效

- 确认你打开的是斗鱼的页面（网址包含 `douyu.com`）
- 点击浏览器右上角的 Tampermonkey 图标，确认 **"斗鱼直播美化"** 前面有打勾
- 如果没有打勾，点击它启用脚本，然后刷新页面

### 某个元素没有被移除

- 斗鱼页面结构可能随版本更新变化，部分选择器可能失效
- 尝试在设置面板中关闭再重新开启对应的开关，然后刷新页面
- 如果问题持续，可以手动在设置面板中找到对应选项确认是否已开启

### 想恢复默认设置

- 打开设置面板，点击右上角 ✕ 关闭
- 点击 Tampermonkey 图标 → 找到脚本名称旁的菜单 → 选择"恢复默认设置"
- 或者在 Tampermonkey 管理面板中删除脚本后重新安装

### 快捷键不生效

- 确认当前焦点不在输入框中（单字母快捷键在输入框中会被禁用）
- 确认没有按住 `Ctrl` 或 `Alt` 等修饰键（`Alt + S` 除外）
