# 时间线净化 - 小红书 / 微博

> 一个让小红书与微博信息流回归「只看内容」的 Tampermonkey 用户脚本。

小红书和微博的网页端信息流里，登录提示、左右侧栏、顶部横幅、直播入口和推广卡片会不断抢占注意力。这个脚本用 `document-start` 样式注入和轻量 DOM 过滤，把时间线整理成干净、居中、可专注阅读的版面；所有改动即时生效，也可以随时在悬浮面板里逐项关闭。

---

## 功能一览

### 界面净化

| 功能 | 默认 | 说明 |
|---|:---:|---|
| 隐藏广告推广 | ✅ | 过滤带「广告 / 赞助 / 推广 / 品牌合作」标记的卡片 |
| 隐藏推荐内容 | ✅ | 过滤带「推荐 / 为你推荐 / 猜你喜欢」标记的卡片 |
| 隐藏直播卡片 | ✅ | 信息流中的直播入口不再打断阅读 |
| 隐藏短视频 / 视频笔记 | ⬜ | 只保留图文内容，减少视频自动播放；默认关闭 |
| 隐藏登录提示 | ✅ | 关闭登录弹窗、登录浮层，并解除弹窗带来的页面滚动锁 |
| 隐藏左侧导航 | ✅ | 收起小红书频道栏或微博左侧导航 |
| 隐藏右侧栏 | 微博 ✅ | 移除微博右侧热搜、关注推荐等模块 |
| 隐藏顶部大图 | 微博 ✅ | 收起微博顶部 Hero 横幅，直达时间线 |
| 隐藏悬浮工具 | 小红书 ✅ | 隐藏页面右下角的「只看图文 / 刷新」悬浮按钮 |

### 外观与阅读

| 功能 | 默认 | 说明 |
|---|:---:|---|
| 顶栏视觉净化 | ✅ | 毛玻璃顶栏、弱化多余入口，保留搜索与频道切换 |
| 居中时间线 | ✅ | 隐藏侧栏后把内容容器稳定居中，不强行拉宽卡片 |
| 柔和纸张主题 | ✅ | 暖白背景、轻盈卡片与柔和阴影，降低视觉噪音 |
| 专注模式 | ⬜ | 隐藏顶部导航和左右侧栏，只留下时间线 |
| 显示悬浮开关 | ✅ | 右下角保留「✦ 时间线净化」入口 |

### 平台适配

| 平台 | 时间线处理 |
|---|---|
| 小红书 | 隐藏左侧频道栏和右下悬浮工具；保留 980px 四列瀑布流，容器最大 1028px 居中；顶栏右侧多余入口弱化 |
| 微博 | 隐藏左侧导航、右侧热搜与顶部 Hero；保留原生 642px 阅读列并水平居中 |

### 交互

- 点击右下角 **✦ 时间线净化** 打开设置面板；
- 「净化 / 外观」两个分组，所有开关**即时生效并自动保存**；
- 快捷键：`Alt + Shift + S` 打开/收起设置面板，`Alt + Shift + Z` 切换专注模式，`Esc` 关闭面板；
- Tampermonkey 菜单提供「打开设置 / 切换专注模式 / 恢复默认」三个入口；
- 面板使用 Shadow DOM 隔离，不污染站点样式。

## 安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://scriptcat.org/)；
2. 点击 **[⚡ 一键安装《时间线净化》](https://github.com/e69d8e/tampermonkey-scripts/raw/main/social-feed-cleaner/social-feed-cleaner.user.js)**；
3. 在脚本管理器弹出的安装页点击「安装」；
4. 打开 [小红书探索页](https://www.xiaohongshu.com/explore) 或 [微博首页](https://weibo.com/) 即可看到效果。

> 脚本匹配小红书与微博域名。两个站点均有多种页面类型，脚本只对信息流相关容器应用布局规则，不会修改账号资料、发布内容或私信数据。

## 使用说明

### 第一次打开

脚本会自动应用默认净化配置：

- 小红书：左侧频道栏收起，四列卡片居中，右下角出现「✦ 时间线净化」；
- 微博：左侧导航、右侧热搜和顶部横幅收起，642px 时间线居中；
- 登录弹窗自动隐藏，页面保持正常滚动；
- 推广、推荐和直播卡片会被标记并在视觉上移除。

### 设置面板

点击右下角悬浮按钮后可以看到两个分组：

- **净化**：广告、推荐、直播、短视频/视频笔记、登录提示、左侧导航、右侧栏、顶部大图、悬浮工具；
- **外观**：顶栏视觉、居中时间线、柔和主题、专注模式、显示悬浮开关。

每次修改都会立即写入 Tampermonkey 本地存储，不需要刷新。点击「恢复默认」可恢复为上表默认值。

### 快捷键

| 快捷键 | 功能 |
|---|---|
| `Alt + Shift + S` | 打开 / 关闭设置面板 |
| `Alt + Shift + Z` | 切换专注模式 |
| `Esc` | 关闭设置面板 |

## 配置项

配置保存在 `GM_setValue('socialFeedCleanerConfig')`，未安装用户脚本时会降级为 `localStorage`。完整配置模型：

```typescript
interface SocialFeedCleanerConfig {
    cleanHeader: boolean;      // 顶栏视觉净化
    hideLeftNav: boolean;      // 隐藏左侧导航
    hideRightSidebar: boolean; // 隐藏右侧栏（微博热搜、推荐等）
    hideHeroBanner: boolean;   // 隐藏顶部大图（微博）
    hideLoginPrompt: boolean;  // 隐藏登录弹窗与浮层
    hideFloating: boolean;     // 隐藏小红书右下悬浮工具
    hideSponsored: boolean;    // 过滤广告与推广卡片
    hideRecommended: boolean;  // 过滤推荐内容卡片
    hideLiveCards: boolean;    // 隐藏直播卡片
    hideVideoCards: boolean;   // 隐藏短视频 / 视频笔记（默认关闭）
    centerFeed: boolean;       // 居中时间线
    softTheme: boolean;        // 柔和纸张主题
    zenMode: boolean;          // 专注模式
    showFab: boolean;          // 显示右下角悬浮开关
}
```

## 常见问题

**Q：安装后页面没有变化？**

1. 确认地址是小红书探索页或微博信息流页，而不是登录页、发布页或私信页；
2. 确认 Tampermonkey 已启用该脚本；
3. 刷新页面。脚本使用 `document-start` 注入样式，刷新后会在首屏渲染前完成净化。

**Q：为什么小红书不是满屏多列？**

小红书信息流本身按固定 980px 四列网格渲染，单纯放大容器不会自动增加列数。脚本保持 980px 四列宽度，只把外观容器限制在 1028px 并水平居中，避免出现半列或大片空白。

**Q：微博时间线为什么只有 642px 宽？**

这是微博原始的阅读列宽度。脚本隐藏左侧导航和右侧栏后，把原本 932px 的容器收缩到 642px 并居中，保持图片、正文和卡片的原始比例，不强行拉伸。

**Q：隐藏登录提示后页面不能滚动？**

脚本会同时移除小红书登录弹窗带来的 `reds-lock-scroll` 滚动锁；如果仍遇到异常，请刷新页面，或在面板中临时关闭「隐藏登录提示」后重新打开。

**Q：为什么默认不隐藏视频笔记？**

视频笔记在小红书和微博都是正常内容的一部分，默认保留可以减少误过滤。需要只看图文时，在「净化」中开启「隐藏短视频」即可。

**Q：脚本会不会删除页面节点？**

不会。脚本只通过 CSS `display: none !important` 和 `data-*` 标记隐藏元素，不调用 `.remove()`，避免破坏 React / Vue 的列表更新。

## 技术说明

- **零闪烁净化**：`document-start` 注入平台样式，先隐藏侧栏与登录层，避免页面渲染完成后再闪烁。
- **平台适配层**：按 `location.hostname` 选择小红书 / 微博的 CSS 选择器和过滤策略，共享同一套配置与 UI。
- **Shadow DOM 设置面板**：自定义 UI 挂在 `#sfb-ui-host` 的 Shadow Root 中，不受站点全局 CSS 影响。
- **MutationObserver 守护**：信息流动态加载新卡片时，180ms 节流重扫广告、推荐、直播与短视频卡片。
- **滚动锁修复**：隐藏登录弹窗时同步移除小红书 `reds-lock-scroll` 类，保证时间线可正常滚动。
